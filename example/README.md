This shows an example of how the multi-physisc modeling tool and the life consumption estimation tool can be combined with WEC-Sim to analyze the damages done to the power electronic converter in a WEC system.

Please note that WEC-Sim must be already installed before this example can be run. Follow the steps provided in the WEC-Sim documentation (https://wec-sim.github.io/WEC-Sim/main/index.html) for the installation procedure.
